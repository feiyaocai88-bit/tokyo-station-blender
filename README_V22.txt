东京站 V22：中央线连续顶棚外形修正

依据用户新提供的斜俯视照片，重新制作中央线 1／2 号站台的顶部外形：
1. 浅绿色宽幅屋面与两侧连续深色弧面连接，替换此前较低的折线屋面及独立弧梁。
2. 完整横向门式框架从外侧屏板立柱沿曲线越过屋顶，配上大块面板分缝、压条、纵向连接条、底座、螺栓和雨水管。
3. 中段增加照片可见的白色横向凸起棚体，有弧形外壳、卷边、下部框架和承托。照片不能确定其用途，未把它命名为办公室或设备楼。
4. 去掉照片不支持的通用屋顶小屋；原物件仍保存在 V22_Replaced_hidden。
5. 按用户后续确认，补齐中央线高架外侧向下连接 3／4 号站台顶棚的 8 组设备：带检修门、百叶、铰链和把手的设备箱，连续矩形下接管槽、法兰抱箍、支架、配管，以及贴合下层斜屋面的泛水基座。

接触网与保留内容
所有电杆、接触线、承力索、吊弦、绝缘子以及吊杆下端和下部定位装置的几何、坐标均保留。原来会穿过新弧面外壳的中央线横向桁架部分改为棚内弧形支承梁，吊杆的上端和固定板适配其高度；其他站台的桁架与吊挂几何保持原样。新屋面留出杆身穿孔。中央线棚下的柱子、吊顶、灯具、摄像头、工作室、端部小通道、列车及站台设施继续使用 V21 内容。

来源和精度
唯一新增外形依据是用户提供的“照片 1.jpg”。拍摄时间、作者、相机参数及现场尺寸未提供。该照片只作目视参照，不作为纹理或随发布包分发。
连续外壳、色块、横框和白色凸棚的相对形态来自照片；高度、跨度、框架间距、白棚精确位置及接触网支承做法是适配现有模型的估计，不构成实测结构复原。上下层设备连接来自用户明确指出并确认的连接关系，8 组的数量、布置、截面尺寸和设备内部用途未获现场测量，不作为实测设备清单。

使用
打开 Tokyo_Station_Chuo_Roof_V22.blend。新增内容在 V22_ 集合内，旧件保存在 V22_Replaced_hidden，主场景内提供 7 个 V22 检查相机。previews 包含顶部、白棚、端部、站台内部、上下层设备连接及全站视图，并有与 V21 相同机位的前后对照。模型自带的既有 V21 相机仍可用于查看其余站台。
源码在 scripts；来源记录在 sources_and_licenses/chuo_roof_v22.json；检查结果在 validation/validate_v22.json；manifest.json 记录发布所用提交与文件哈希。
