东京站 V19 — 丸之内站舍背面与连续道路

基于完整 V18。保留前序站舍、列车、站台、轨道和地下剖面。

本次修改
1. 站舍与中央线高架之间：将原先分段的后部顶棚整合，沿背立面轮廓
   设置连续采光带、分格金属顶、窗框和檐沟；补齐原缺口。
   顶棚随南侧折线后翼收窄，在模型可用空间结束处收口。
2. 补连廊石材地面、钢柱、底板螺栓、斜撑、雨水管及管卡、暖色灯带、
   灯具、旅客和指示牌。增加屋面风机、百叶、风管、检修口和护栏。
3. 补两端设备楼周边铺地、格栅排水、检修设施、护柱及壁灯。
4. 将外围马路重建为相连的路面，统一沥青与接口标高，圆顺转角。
   清除新道路穿越原南侧铺装处的旧路缘，连接交通广场和沿高架道路。
   南侧路段绕开已建高架下空间，北侧路段避让设备楼。
5. 将旧交通广场残留的大块沥青改为衔接人行道，补连续路缘、街灯、
   路面排水、井盖、车道虚线、导向箭头、停止线、斑马线及交通信号。
   保留 V18 草坪与交通岛布局，M7/M8 的地下入口开口继续保持畅通。

使用
打开 Tokyo_Station_Connections_V19.blend（Blender 5.2 LTS）。
默认相机为 V19 01 Streets overview。V19_Review_Cameras 中有 7 个视角，
包括背面、道路、俯视和连廊内部。previews 中有最终图和同机位对比。
被替换的源对象完整保留在 V19_Replaced_hidden 中。

复现
scripts/mod19_connections.py 从 V18 完整文件构建 V19，使用同目录
streets_v19.json，Blender 不需要另装 GIS 依赖。
scripts/validate19_connections.py 检查源对象保留、实际道路通行面、
连廊净空、顶棚覆盖以及地铁入口；报告在 validation 文件夹。
街道规划 JSON 如需重新生成，可先从 V18 运行 export19_source.py，
再用 CPython 和 Shapely 2 运行 prepare19_streets.py。
