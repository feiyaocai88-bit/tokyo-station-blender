本次修改
1. 中央线隔音屏原本超过高架末端近百米，已依照桥面实体的起止位置截短。屏体移回桥边，并增加连续压顶和向内搭接的支座；新干线东侧同样校正。
2. 保留20条地面轨道的轨枕、扣件与钢轨标高，降低道砟填充面60毫米；补入实体碎石、轨旁线槽盖、接线箱和钢轨跨接线。模型中可直接看到轨枕的截面层次。
3. 北端、南端及八重洲侧设备楼补齐端墙百叶、门框、门把、雨棚、灯具、落水管、风管法兰、检修步道及屋顶压边。站房后侧增加排水格栅与检查井盖。
4. 中央御车寄换为圆形砖石柱、分层檐口、拱顶石帽、内凹门洞和铁艺双门；补齐石栏杆、修剪松树、台座与站名石碑。
5. 增加M8和M7地面楼梯入口，每处36级台阶和中间平台，带扶手、盲道、玻璃围护、灯箱和照明；底座及地坪真实开孔，地下通道连接到原有丸之内线B1。
6. 导出接触网杆位核查记录，补齐接地线、抱箍及地脚螺栓。

精度说明
接触网不能声称逐根与实景一致。旧版以约22米间距生成并做避障；目前照片可以核对结构类型和与站台的相对关系，但不足以确定每一根杆的实测坐标。详见 validation/catenary_audit_v13.csv 与来源文件。
M7/M8的位置及通道长度是适配现有简化广场和V11地下站的估算，路径在模型中连续可走。周边建筑中的M9/M10出入口不属于本次建模范围；M10地面电梯没有被错误添加在M8入口旁。
照片来源跨不同年份，新增的小型机电构件与雕饰为解释性模型；不能作为施工、测量或现场导航依据。
