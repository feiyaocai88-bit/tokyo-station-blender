东京站 V18 — 丸之内站前广场实景对照修正

本版基于完整 V17，保留已连通的站舍、地面列车、站台、轨道、接触网、
南侧高架地面及地下展示剖面。

对照发现与修改

1. 中央白色通道原先偏离中央入口轴线，草坪长度、位置不一致。
   将中央轴线对齐 X=0，重新铺设白色大板及两侧深浅灰花岗岩拼铺。
   两块草坪各 15×40 米，合计 1,200 平方米；补细六角柱及下垂绳栏。
2. 原树阵每侧 5 株，树池与实景的宽石座、内凹基座差别较大。
   调整为每侧 7 株，重做枝叶、植被床、石座和座下灯带。
   三灯照明改成黑色细杆、三个竖向长灯罩的造型，沿树阵内侧布置。
3. 两块夏季打水铺地增加深灰拼铺、齐平金属边、喷水口和周围排水槽。
   默认展示干燥状态，未做成深水池。
4. 原来的大块矩形雨棚遮住了交通广场。
   按竣工航拍可见的关系，重做南北不同轮廓的交通环路、开放式出租车
   蓄车区、白线分格、候车护栏、站牌和细钢柱悬挑玻璃棚。
   北侧通风塔以保留细节的复制件调整到新交通岛内。
   补车辆轮胎、窗框、灯具、后视镜等，地面车辆作为交通广场配景。
5. 环路增加接向外围道路的开口；出租车区有真实路缘缺口及连续坡面。
   行人过街条纹调整至中央轴线两侧，并补盲道提示块。
6. 重新安排行人，避开草坪和树池。M7/M8 已有地下入口保持真实开口，
   新地面没有封住楼梯或地下一层连接。
